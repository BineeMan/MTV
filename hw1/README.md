# Домашнее задание №1: Лексический анализатор (LexerEngine) для языка Funny

Шаги алгоритма состоят из:
1. Парсинга регулярных выражений в AST.
2. Построения НКА по алгоритму Томпсона.
3. Детерминизации НКА в ДКА (Subset Construction).
4. Минимизации ДКА по алгоритму Хопкрофта.
5. Токенизация по построенному супер-ДКА

---

## Инструкция по запуску

### 1. Установка зависимостей

Убедитесь, что у вас установлен Node.js (версии 18+). Для установки пакетов выполните:

```bash
npm install

```

### 2. Запуск

Для проверки работы лексера на наборе юнит-тестов (Vitest):

```bash
npm test

```

Запуск точки входа проекта (`src/index.ts`) через `tsx`:

```bash
npm start

```

### 1. Список регулярных выражений

## Исходный набор регулярных выражений (язык токенов)

- `IDENT`: `[A-Za-z_][A-Za-z0-9_]*`
- `INT`: `0|[1-9][0-9]*`
- `WS`: `[ \\t\\r\\n]+`
- `COMMENT`: `//[^\\n]*`
- Ключевые слова: `function|returns|uses|while|if|else|true|false`
- Разделители/операторы: `\\+|-|\\*|/|==|!=|<=|>=|<|>|=|,|;|\\(|\\)|\\[|\\]|\\{|\\}|not|and|or`
- Алфавит входа: ASCII (фиксирован в спецификации Funny).


### 2. Размер ДКА до и после минимизации

* **Исходный ДКА:** `346` состояний.
* **Минимизированный ДКА** `71` состояний.
