# HW3. Семантический анализатор (Funny)

Модуль статического анализа для проверки типов, областей видимости и автоматического вывода типов локальных переменных в AST языка Funny.

## Запуск и тесты

```bash
npm install
npm run test_semantics

```

---

## Поддерживаемые конструкции

* **Типы:** `int`, `int[]`, внутренний `boolean` (для условий).
* **Объявления:** функции (`function`), контракты (`requires`, `ensures`), локальные переменные (`uses`), предикаты (`formula`).
* **Операторы:** присваивание (одиночное, обновление массива `a[i] = v`, кортежное), `if-else`, `while` (с `invariant`), `assert`, `assume`, блоки `{}`.
* **Выражения и предикаты:** арифметика, индексация, вызов `length(a)`, логические операции (`and`, `or`, `not`, `->`), кванторы (`forall`, `exists`).

---

## Ключевые проверки

1. **Таблица символов:** вложенные области видимости, контроль уникальности имён, проверка вызова необъявленных символов.
2. **Защита параметров:** аргументы функций помечаются как `Read-Only` (присваивание в них запрещено).
3. **Проверка типов:** строгое соответствие типов в арифметике, вызовах функций/формул и логических условиях.
4. **Вывод типов локальных переменных (Бонус +2 б.):** тип переменных из `uses` выводится по первому присваиванию; противоречивые повторные присваивания вызывают ошибку.
5. **Аннотированный AST и диагностика:** простановка `inferredType` для всех узлов выражений и сбор списка ошибок с точными позициями (`position`).
